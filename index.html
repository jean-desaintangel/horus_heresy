    Utiliser le site hors ligne

    1. Sur votre téléphone, ouvrez le site dans Chrome, avec une connexion internet.
    2. Attendez quelques secondes que la page se charge complètement — c’est le moment où le contenu est téléchargé pour l’usage hors ligne.
    3. Appuyez sur les trois points verticaux (⋮) en haut à droite.
    4. Appuyez sur « Installer l’application » (parfois affiché directement en bannière en bas de l’écran, sans passer par le menu).
    5. Confirmez avec « Installer ».
    6. Une icône avec le blason Emperor’s Children apparaît sur votre écran d’accueil.
