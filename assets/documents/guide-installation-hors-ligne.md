# Installer le site en app hors ligne (Chrome)

Guide rapide pour avoir le site Horus Heresy sur l'écran d'accueil, utilisable
sans réseau.

## Sur téléphone Android (Chrome)

1. Ouvrez **https://lagrandecroisade.fr/** dans Chrome,
   avec du Wi-Fi ou de la 4G/5G (chez vous, pas en boutique).
2. Attendez quelques secondes que la page se charge complètement — c'est le
   moment où le contenu est téléchargé pour l'usage hors ligne.
3. Appuyez sur les **trois points verticaux** (⋮) en haut à droite.
4. Appuyez sur **« Installer l'application »** (parfois affiché directement
   en bannière en bas de l'écran, sans passer par le menu).
5. Confirmez avec **« Installer »**.
6. Une icône avec le blason Emperor's Children apparaît sur votre écran d'accueil.

## Sur ordinateur (Chrome)

1. Ouvrez le site dans Chrome.
2. Dans la barre d'adresse, cliquez sur l'icône d'installation (petit écran
   avec une flèche, à droite de l'URL). Sinon : menu ⋮ → **« Installer
   Horus Heresy... »**.
3. Confirmez.

## Vérifier que ça marche vraiment hors ligne

1. Lancez l'app depuis son icône (pas depuis un onglet Chrome classique).
2. Activez le mode avion.
3. Naviguez dans les fiches d'unités, l'Arsenal, le glossaire : tout doit
   s'afficher normalement.

## À savoir

- La première ouverture **doit** se faire avec du réseau : c'est elle qui
  télécharge le contenu (environ 11 Mo).
- Après une mise à jour du site, rouvrez
  l'app une fois avec du réseau pour récupérer la dernière version — sinon
  vous gardez simplement la version précédente.
- Si « Installer l'application » n'apparaît pas dans le menu Chrome, c'est
  probablement que la page n'a pas fini de charger.
